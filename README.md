## 🚀 Getting Started

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/Abhilash-S123/Personal-website-Dev..git
cd Personal-website-Dev.
```

2. **Install dependencies**
```bash
npm install
```

3. **Start development server**
```bash
npm run dev
```

4. **Open in browser**
```
http://localhost:5173
```

### Build for Production

```bash
npm run build
```
